# New General Service List (NGSL) -- source and license

`ngsl_common_words.txt` in this directory is the word list from the **New
General Service List (NGSL) version 1.2**, extracted verbatim from the
"NGSL 1.2 alphabetized with description" file published at
https://www.newgeneralservicelist.com/new-general-service-list (downloaded
2026-09-29), with the file's leading description paragraph and changelog
table stripped -- only the 2,809 alphabetized lemma words remain, one per
line, unmodified and unfiltered otherwise.

**Authors:** Browne, C., Culligan, B., and Phillips, J.

license statement published on the NGSL project's own site: "New General

under a Creative Commons Attribution-ShareAlike 4.0 International License."

**Why this list**: NGSL is a pedagogical vocabulary list (the ~2,800 words
that give ~92% coverage of general English text for language learners),
curated from a 273-million-word academic corpus specifically to teach core
vocabulary -- not a raw word-frequency dump of a news/web corpus. Verified
directly (not assumed) before use: it contains zero of a sample set of
common place names (Singapore, Tokyo, Paris, London, China, Lagos, Bangkok,
Manila, Moscow, Seattle, Russia, Nigeria, Thailand, Philippines), unlike
several other freely available "10,000 common English words" lists (e.g.
lists derived from Google's Trillion Word Corpus / Peter Norvig's n-gram
frequency data), which were checked first and rejected specifically because
they do include lowercased place names.
